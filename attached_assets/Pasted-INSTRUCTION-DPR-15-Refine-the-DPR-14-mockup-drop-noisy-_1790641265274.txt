PART A — Remove noisy badges above the activity field grid
Each activity row currently shows three pill badges above its field grid: "BOQ progress", "Quantity from sample geometry", "Unit: CUM". Remove the first two — they add no information the person needs. Keep a BOQ-unit indicator only if the unit isn't otherwise obvious from the Physical Qty field's own label (e.g. if the qty field is already labelled "Physical qty (CUM)", a separate "Unit: CUM" badge is redundant too — use judgment, but default to removing all three unless you find a real case where the unit would be ambiguous without it).

PART B — One row for all activity fields
Currently Side / From (Ch.) / To (Ch.) / Length (m) / Width (m) / Thickness (m) are one row, and Layer/lift no. / Physical qty (CUM) sit on a second row below. Combine all eight fields (side, from, to, length, width, thickness, layer/lift, physical qty) into a single row, adjusting column widths so it stays readable (narrower columns for short fields like Side/Layer, proportionally more space for numeric fields). Confirm this still reads cleanly at the mockup's normal viewport width — if eight columns genuinely can't fit without becoming illegible, say so in your report and propose the best compromise (e.g. wrapping to two rows only when the viewport is narrow) rather than forcing it and producing a broken layout.
