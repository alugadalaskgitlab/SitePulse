Implementation choices

  • Existing vendor names must resolve to exactly one existing vendor-master ID. No vendor names are created or merged.
  • PI and arrangement vendor prefill goes into Material from. Client-supplied text is not appended to a vendor name.
  • A focused role-only editor was added to this list because this page had no existing edit action. It only writes after explicit Save roles.
  • All defaults to all role states; selecting a role clears the legacy missing-source checkbox so unresolved rows with a source are not hidden.
  • The existing bulk tool is disabled while a role filter is active because the bulk endpoint does not accept that filter. No bulk assignment was executed.
  • Validation is scoped to this entry flow; global trip endpoints and other entry flows were left unchanged.
