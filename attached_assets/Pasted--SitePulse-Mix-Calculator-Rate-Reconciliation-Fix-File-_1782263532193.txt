# SitePulse — Mix Calculator Rate Reconciliation Fix

**File to edit:** `client/public/mix-calculator.html`
**Goal:** Make **"Plant Subtotal"**, **"Detailed Scope of Work"**, and **"Scope Breakdown"** all reconcile to the same cost basis.

---

## Why the three numbers disagreed (root cause)

The calculator had **three independent cost engines** that each computed bitumen & aggregate differently:

| Panel | Engine | Mix used | Wastage applied? | Margin baked in? |
|---|---|---|---|---|
| **Plant Subtotal** (Rate Summary) | `mixRates` | each mix (per-mix) | ✅ yes | ❌ no |
| **Detailed Scope of Work** | `calcScopeComponents` | **AVERAGED across all mixes** | ❌ no | ✅ yes |
| **Scope Breakdown** | `renderScopePanel` | **mixTypes[0] only** | ❌ no | ✅ yes |

So e.g. `5516` (Plant Subtotal) vs `5922` (Detailed Scope) vs `6349` (Scope Breakdown) came from: averaging instead of using the selected mix + missing aggregate/bitumen **wastage** + **margin** being mixed into the displayed cost.
> The earlier "average rates across mix types" change made this **worse**, not better.

## The fix (agreed approach)

1. **Single source of truth** = the per-mix **Plant Subtotal** basis (selected/active mix, *with* aggregate & bitumen wastage, **no margin**).
2. Scope panels use the **active/selected mix only** (not an average, not always mix #1).
3. Scope panels show **pre-margin cost** (so they match Plant Subtotal), with **margin on a separate, clearly-labelled line**.

Apply the 8 find/replace edits below **exactly** (whitespace matters). All edits are inside `client/public/mix-calculator.html`.

## After applying — how to verify (2 min)

1. Open the Mix Calculator, set a single mix type, and set **Margin = 0** in the Scope section.
2. **Mixing-only scope** (Quote mode = *Supply only*, all mixing components checked, transport/laying off):
   - **"Scope Cost (₹/MT)"** in the Scope Breakdown panel should now **equal** the **"Plant Subtotal"** in the Rate Summary table (to the rupee).
   - **"Detailed Scope of Work" → Mixing** rate should equal the same Plant Subtotal.
3. Set **Margin = 10%** → the cost rows stay the same; a separate **"Margin (10%)"** line + **"Quoted Rate"** appear. Quoted Rate = Cost × 1.10.
4. Switch the **active mix tab** → all three panels update to that mix's numbers (no more "always mix #1" or averaging).

> Expected result: the old `5516 / 5922 / 6349` spread collapses — the cost figures match Plant Subtotal, and margin is the only intentional add-on, shown on its own line.
