---
name: Batch report delivery
description: Required report-file and Git delivery format for future project batches.
---

For every batch, write the Part A report and the final report to `reports/<BATCH-NAME>.md`, commit and push the report to `origin/main`, and reply in chat with exactly one line: `Report pushed: reports/<BATCH-NAME>.md`.

**Why:** the owner explicitly requested this reporting and delivery format for all future batches.

**How to apply:** keep each batch's findings and outcomes in its named Markdown report; commit and push it before the final response. Do not add explanatory chat text beyond the one-line report confirmation.
