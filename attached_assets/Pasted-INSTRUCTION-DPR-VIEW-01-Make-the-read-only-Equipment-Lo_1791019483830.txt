=====================================================================
NEW SHARED HELPER (pure, tested): shared/dprEquipmentConsumption.ts
=====================================================================
export function resolveDprRowConsumption(input): {
  basis: "measured" | "issued" | "incomplete";
  value: number | null;            // in displayUnit
  displayUnit: "L/hr" | "km/L" | null;
  norm: number | null;             // in displayUnit
  deviationPct: number | null;     // signed; positive = WORSE than norm
  flag: "ok" | "worse" | "better_check" | null;
  reason: string | null;           // 2–6 words when incomplete, e.g. "closing reading missing", "no diesel recorded", "diesel by vendor"
}
Inputs: the row's runtime and unit exactly as buildDprEquipmentTableDetails already derives them (historicalUsage.runtime + efficiencyUnit "L/hr" | "L/km" — reuse that, do not recompute hours/km), diesel issued (row.diesel), fuel.actualConsumed and row.dieselBalanceConfirmed from the same builder, the norm from details.norm (resolveEquipmentConsumptionNormRate) with fallback to the row's saved dieselNorm, and the canonical result from resolveDprActualEfficiency when available.
Rules, in order:
1. MEASURED: if the canonical result is "available" → use it. Else if row.dieselBalanceConfirmed === true and fuel.actualConsumed != null and runtime > 0 → actualConsumed ÷ runtime. basis = "measured".
2. ISSUED: else if diesel issued > 0 and runtime > 0 → issued ÷ runtime. basis = "issued".
3. INCOMPLETE: otherwise value = null with a short reason (runtime missing → "hours/km not available" or "closing reading missing" when opening exists without closing; diesel missing → "no diesel recorded"; dieselSource "contractor" with no diesel → "diesel by vendor").
Units: machines (L/hr basis) display L/hr. Vehicles (L/km basis) display km/L = 1 ÷ (L/km); convert the norm the same way. Never divide by zero; guard non-finite values.
Deviation and flag (threshold 10%, as a named constant CONSUMPTION_FLAG_PCT = 10):
- L/hr: deviationPct = (value − norm) ÷ norm × 100. km/L: deviationPct = (norm − value) ÷ norm × 100 (so positive always means worse).
- |deviation| ≤ 10 → "ok"; deviation > 10 → "worse"; deviation < −10 → "better_check" (unusually low consumption usually means a missing diesel entry or wrong reading — show as amber "check", not green).
- No norm or incomplete → flag null.
Unit tests: measured beats issued; canonical beats row-level; L/km→km/L conversion of value and norm; ±10% boundaries; zero/negative/missing inputs; contractor diesel; a row whose canonical state is "unavailable" for access reasons still gets a row-level figure.
