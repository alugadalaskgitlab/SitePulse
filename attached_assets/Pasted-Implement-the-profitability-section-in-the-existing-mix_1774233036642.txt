FORMULA BASIS

1) Revenue
Revenue must remain contract-based.
Use the currently selected commercial mode and existing revenue logic already present in the app.

Possible sources may include:
- itemised contract rates
- per km rate
- lumpsum
- stored contract value

Use the existing source of truth already used for contract revenue.
Final display should be total revenue for that site/job.

2) Full Job Cost
This is the full technical total cost from the estimator/costing engine.
Do not change how the technical full job cost is calculated.

3) In-Scope Cost
This is the sum of only those cost components that are selected in the existing scope checkbox system.

Formula concept:
In-Scope Cost =
sum of all included cost components where the corresponding scope selection is true

Examples:
- if bitumen is selected in scope, include bitumen cost
- if bitumen is not selected, exclude bitumen cost from profitability
- if transport to site is selected, include that cost
- if transport to site is not selected, exclude it from profitability

4) Excluded Cost
Excluded Cost = Full Job Cost - In-Scope Cost

5) Profit
Profit = Revenue - In-Scope Cost

6) Margin %
Margin % = (Profit / Revenue) × 100

If Revenue is zero, handle safely and avoid divide-by-zero issues.

SCENARIO LOGIC

If a scenario is active:
- Revised In-Scope Cost = in-scope cost recalculated using scenario/revised rates
- Delta ₹ = Revised In-Scope Cost - Base In-Scope Cost
- Profit should reflect the revised in-scope cost
- Margin % should reflect the revised in-scope cost
