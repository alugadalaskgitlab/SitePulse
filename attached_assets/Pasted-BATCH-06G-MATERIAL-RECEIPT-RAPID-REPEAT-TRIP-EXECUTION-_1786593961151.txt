--------------------------------------------------
2. DPR RECEIPT STRIP MUST NOT HIDE JUST BECAUSE RECEIVED = ZERO
--------------------------------------------------

Current ActivityReceiptStrip suppresses itself when there is:

- no resolved arrangement;
- no linked trip;
- no suggested trip.

That causes the Engineer to see no material/execution context at all.

Remove that overly broad hide rule.

For a receipt-relevant billable activity, the strip should remain visible
even before the first truck arrives.

Example:

EMBANKMENT — BORROW EARTH

Execution Arrangement:
MARSIMULU — Borrow Earth supply/carting

Material:
Soil

Required Today:
Not determined

Received Today:
0 Cum

[Record Receipt]

Only suppress the material-receipt strip when:

- `receiptRelevanceForType()` says the activity does not require external
  receipt evidence;

or

- the row is No Site Work and normal material receipt prompting is not
  applicable.

Do NOT use `resolution.none` alone as a reason to hide the strip.

--------------------------------------------------
3. OPERATIONAL FULFILMENT RESOLUTION
--------------------------------------------------

For today's DPR activity, resolve the operational source in this priority:

1. Today's matching PM/allocating-authority daily fulfilment.

2. Exact persisted programmeBarId arrangement allocation.

3. Compatible reach/scope + BOQ item arrangement.

4. Compatible BOQ item arrangement.

5. No applicable arrangement
   → HLC / Main Contractor.

Daily fulfilment is operational context only.

It must NEVER mutate:

- standing Execution Arrangement
- vendor
- scope
- allocated quantity
- programme allocation.

--------------------------------------------------
4. DAILY ALLOCATION SHOULD OVERRIDE DISPLAY/SUPPLIER FOR TODAY
--------------------------------------------------

If PM allocated today's requirement through:

Arrangement A:
show Arrangement A/vendor.

If PM used:

Other Agency / Daily Exception:
show that agency as today's operational supplier,
but do NOT fabricate an earthworkArrangementId.

If PM used:

HLC / Internally Arranged:
show HLC/Internal context.

The standing arrangement remains available as background context where
helpful, but today's operational allocation governs today's supplier
suggestion.
