# BOQ Mapping Review + DPR Item/UOM + Programme Sequencing Fix

Current issue observed in Takkadpally–Sirur project:

1. In Site DPR → Work Item & Qty, BOQ items are appearing under “Other / Unbilled”.
2. BOQ items are not classified into proper categories like Earthwork, Site Clearance, GSB, WMM, Prime Coat, Tack Coat, DBM, BC, Structures, Drainage, etc.
3. The DPR item selector shows full/unclear item descriptions instead of clean short work names.
4. UOM is not reliable in DPR. Example: clearing/grubbing style BOQ item shows NOS and quantity auto behaviour is wrong.
5. Auto-sequence/work programme is placing many/all activities into the first month instead of sequencing by item type, quantity, stage, productivity/duration and road/structure logic.
6. We need an admin/edit screen for imported BOQ items so wrongly imported/mapped items can be corrected manually.

Please fix only this BOQ mapping / DPR item source / sequencing issue.

If not available, derive short name from description.
Full BOQ description should be secondary/expandable only.

C. DPR item picker

Fix DPR BOQ item picker so items do not fall under “Other / Unbilled” unless truly unmapped.

The picker should show:
- category / bill section
- item code
- short work name
- BOQ unit
- balance / planned qty if available

If category is missing:
- show “Needs Mapping” instead of silently treating as Other / Unbilled
- allow admin to open BOQ Review and map it

D. UOM and quantity logic

DPR should use BOQ unit and measurement method.

Rules:
- CUM / m³: L × W × T
- SQM / m² / Ha: L × W, with proper conversion if BOQ unit is Ha
- RMT / m / km: length, with proper conversion if needed
- MT / kg: manual quantity unless linked to production/weighment
- NOS / Each: manual count
- LS / %: manual
- If formula is uncertain, do not auto-calculate wrong quantity. Show manual entry with warning.

Important:
Do not default to NOS for road BOQ items unless BOQ unit is truly count-based.

E. Programme sequencing fix

Fix auto-sequence / auto-generate for road BOQ items.

It should not place all items in Month 1.

Sequencing should consider:
- category / planning work type
- construction order
- quantity
- productivity/duration defaults or SDB/SNL rates if available
- road reaches/fronts
- structure schedule for structure items
- start date and project duration

If sequencing input is missing:
- mark item as Needs Review
- do not silently dump into Month 1

Road sequence example:
Site Clearance
→ Earthwork / Embankment
→ GSB
→ WMM
→ Prime Coat
→ DBM
→ Tack Coat
→ BC
→ Shoulder / road furniture

Structure items should follow imported structure schedule and structure sequence, not road reach auto-spread.
