# SitePulse — Patch 10 · Material Demand from Templates / Mix Designs (key stock materials)

**Goal:** Pull the major key materials from the **actual** templates/designs already in your masters —
no guessing, no defaults:
- **Concrete** (RCC/PCC, M15–M50) → **RMC module** mix design → Cement, Sand, 20mm, 10mm, Admixture
- **Bituminous** (BC/DBM/SDBC/BM) → **Mix Templates in Masters / HMP** → Bitumen + aggregate fractions + LDO
- **Emulsion** → spraying rate parsed from the **BOQ description** (rate kg/sqm × area)
- **Steel** → BOQ qty (already working) · **Diesel/HSD** → equipment hours × norm (Patch 8H Fuel)

**Why nothing showed before:** the BOM route never queried `rmc_mix_designs`, the engine had **no concrete branch at all**, and bituminous only checked per-project links (not the standard templates in Masters). This patch wires all three.

**Files changed:** `shared/planningEngine.ts`, `server/routes.ts`, `tests/planningEngine.test.ts`.
Type-checked clean (`tsc`). After applying, run `npm run check` and `npm run test`.

Units: Cement/Bitumen → **MT**, Sand & Aggregate → **CUM** (converted from kg/m³ using bulk densities sand 1.6 T/m³, coarse agg 1.45 T/m³), Admixture → **kg**, Emulsion → **MT**.

describe("deriveMaterialsFromLayerConfig — bituminous from mix template", () => {
  const baseLayerConfig = {
    layerType: "bituminous" as const,
    thicknessMm: 50,
    densityTPerCum: 2.4,
  };
  const bcTemplate = {
    bitumenPercent: 5.5,
    ldoNorm: 6,
    components: [
      { materialName: "20mm Aggregate", percent: 32 },
      { materialName: "10mm Aggregate", percent: 25 },
      { materialName: "Stone Dust", percent: 35 },
      { materialName: "Filler", percent: 2.5 },
    ],
  };

  it("returns bitumen + aggregate rows from the mix template (plus LDO)", () => {
    const rows = deriveMaterialsFromLayerConfig({ ...baseLayerConfig, mixType: "BC" }, "SQM", bcTemplate);
    expect(rows.length).toBeGreaterThan(1);
    expect(rows.find(r => r.materialName.toLowerCase().includes("bitumen"))).toBeDefined();
    expect(rows.find(r => r.materialName.toLowerCase().includes("aggregate"))).toBeDefined();

    const rows = deriveMaterialsFromLayerConfig({ ...baseLayerConfig, mixType: "BC" }, "SQM", undefined);

    const mtPerSqm = (50 / 1000) * 2.4;
    const rows = deriveMaterialsFromLayerConfig({ ...baseLayerConfig, mixType: "BC" }, "SQM", bcTemplate);
    const mixRows = rows.filter(r => r.materialName !== "LDO / Process Fuel");
    const total = mixRows.reduce((sum, r) => sum + r.qtyPerBoqUnit, 0);
    expect(total).toBeCloseTo(mtPerSqm, 3);
  });

## Prerequisites for data to appear
- **Concrete**: the grade in the BOQ description (M25/M35…) must have a matching **RMC mix design** with `componentProportions` filled (cement / fineAgg / coarseAgg20 / coarseAgg10 in kg/m³). If only `cementContent` is filled, you'll get Cement + Admixture only.
- **Bituminous**: a **standard mix template** for that mix type (BC/DBM…) must exist in Masters with `bitumenPercent` + component %; the item's layer must have thickness + density set.
- **Emulsion**: the BOQ description must contain a rate like "0.25 kg/sqm" (or set the layer coverage rate).
