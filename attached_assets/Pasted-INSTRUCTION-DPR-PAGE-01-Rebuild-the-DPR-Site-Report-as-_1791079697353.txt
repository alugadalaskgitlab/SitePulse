3. WORK DONE table — one row per activity:
   Item (+ side under it) | Chainage from → to | Size (L × W × T) | Quantity | Programme

4. EQUIPMENT table — one row per machine, no expand control:
   Machine (name + reg; second line "Hired · vendor · hire type · Op. <operator>" or "Owned · Op. <operator>") | Work (BOQ item, or "General", or "Not linked"; task text on a second small line) | Hours | Diesel | Consumption

   - Consumption: value + unit (L/hr machines, km/L vehicles), then "norm 9.0" small, then the deviation mark. THE MARK MUST APPEAR ON EVERY ROW WHOSE DEVIATION IS MORE THAN 10%: red "▲16%" when worse than norm, amber "▼60% check" when better than norm by more than 10%. Within 10% → no mark.    - Idle/Breakdown rows: show the status chip and the reason instead of consumption.
   - Totals row: hours (1 decimal), diesel issued (whole/1 decimal), "20.5 L used · 25.8 L expected". Never 3 decimals. Hide km when no vehicle; hide "used" when no machine has a confirmed tank figure.
   - Legend, exactly one line under the table: "Consumption from tank dip (opening + issued − closing). ▲ more than 10% above norm · ▼ check more than 10% below (often a missed diesel entry) · no mark = within 10%." Nothing else.
