Refine the profitability revenue-adjustment behavior for Per KM mode so that the adjustment is entered per KM, not only as an overall total amount. Keep the UI clean, readable, and consistent with the existing profitability section. Do not redesign the whole page.

PURPOSE
In Per KM mode, the contract revenue is entered as Contract Rate / KM. Therefore, the commercial adjustment should also be entered per KM so the system can automatically calculate the total revenue impact without the user manually converting it into a total lump sum.

IMPORTANT CONSTRAINTS
- Apply this change only to Per KM mode in the profitability/commercial section.
- Do not disturb Itemised mode, Lumpsum mode, estimator logic, procurement, or scenario cost logic.
- Keep readability strong.
- Avoid tiny text, faint text, or too many colors/bands.
- Keep the layout simple and uncluttered.
- Check cursor focus/typing behavior in the new field.

REQUIRED CHANGE

1) ADD / REPLACE THE ADJUSTMENT FIELD IN PER KM MODE
In Per KM mode, use a field:

Label:
Commercial Adjustment / KM

Type:
numeric input

Default:
0

This field should represent the additional or reduced commercial amount per KM.

Behavior:
- positive value → increases revenue per KM
- negative value → reduces revenue per KM

Do not force the user to manually convert adjustment into total amount.

2) REVENUE CALCULATION IN PER KM MODE

Base values:
Base Contract Rate / KM = original/base saved contract rate per KM
Total Length = current job/site total length in KM (use existing length source already used for per KM revenue)

Base Revenue:
Base Revenue = Base Contract Rate / KM × Total Length

Revised/current values:
Revised Contract Rate / KM = Base Contract Rate / KM + Commercial Adjustment / KM

Revised Revenue:
Revised Revenue = Revised Contract Rate / KM × Total Length

Total Adjustment Amount:
Total Adjustment Amount = Commercial Adjustment / KM × Total Length

3) PROFITABILITY CALCULATION
Base Profit = Base Revenue - Base In-Scope Cost
Base Margin % = Base Profit / Base Revenue × 100

Revised Profit = Revised Revenue - Revised In-Scope Cost
Revised Margin % = Revised Profit / Revised Revenue × 100

IMPORTANT:
Base Revenue, Base Profit, and Base Margin must remain original/base values only.
Commercial Adjustment / KM must affect only the revised/current side.
Do not let this field alter the Base line.
