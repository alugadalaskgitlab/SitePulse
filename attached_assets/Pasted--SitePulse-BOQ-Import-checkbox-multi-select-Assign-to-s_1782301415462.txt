# SitePulse — BOQ Import: checkbox multi-select + "Assign to selected" bulk category

## How category assignment works **today** (read this first)

In the Import wizard, **Step 2 — Work Category Assignment** already does a lot:

1. **Auto-suggest from item code.** On entering Step 2, `suggestWorkCategory(itemCode)`
   pre-fills the category for every item that has a standard MoRTH/NHAI code
   (`3.xx` → Earthwork, `4.xx` → Sub-base & Base, `5.xx` → Bituminous, etc.).
   So for a properly-coded BOQ, *most rows are already categorised* before you touch
   anything — you don't scroll 200 rows from scratch.
2. **Per-row dropdown.** Each row has a category `<Select>` for manual correction.
3. **Bulk bar (already present).** A "Bulk assign" bar with a category dropdown and two
   buttons:
   - **Set unassigned (N)** — fills only the still-blank rows.
   - **Set all** — overwrites every row with the chosen category.
4. **Gate.** You can't proceed until 0 rows are unassigned.

**The real gap your suggestion fixes:** today bulk-assign is all-or-nothing
("all" or "only blanks"). There is **no way to pick a subset** — e.g. tick the 15
drainage rows and assign just those. That's exactly what checkboxes + "Assign to
selected" add. It fits cleanly because the category state is already an index-keyed
array (`itemWorkCats[idx]`), so assigning to a selected set is a one-line map.

This patch is **frontend-only**, in `client/src/components/BoqImportWizard.tsx`,
and is purely additive (the existing dropdown + "Set unassigned"/"Set all" stay).

## EDIT 2 — reset selection when (re)entering Step 2, and add helpers

**FIND:**

```tsx
  function enterStep2() {
    const cats = parsedItems.map(item => suggestWorkCategory(item.itemCode) ?? "");
    setItemWorkCats(cats);
    setBulkCat("");
    setStep(2);
  }

  function applyBulkCat() {
    if (!bulkCat) return;
    setItemWorkCats(prev => prev.map(c => c === "" ? bulkCat : c));
  }

  function applyBulkCatAll() {
    if (!bulkCat) return;
    setItemWorkCats(prev => prev.map(() => bulkCat));
  }
```

**REPLACE WITH:**

```tsx
  function enterStep2() {
    const cats = parsedItems.map(item => suggestWorkCategory(item.itemCode) ?? "");
    setItemWorkCats(cats);
    setBulkCat("");
    setSelectedRows(new Set());
    setStep(2);
  }

  function applyBulkCat() {
    if (!bulkCat) return;
    setItemWorkCats(prev => prev.map(c => c === "" ? bulkCat : c));
  }

  function applyBulkCatAll() {
    if (!bulkCat) return;
    setItemWorkCats(prev => prev.map(() => bulkCat));
  }

  function applyBulkCatSelected() {
    if (!bulkCat || selectedRows.size === 0) return;
    setItemWorkCats(prev => prev.map((c, i) => selectedRows.has(i) ? bulkCat : c));
    setSelectedRows(new Set());
  }

  function toggleRow(idx: number) {
    setSelectedRows(prev => {
      const next = new Set(prev);
      if (next.has(idx)) next.delete(idx); else next.add(idx);
      return next;
    });
  }

  function toggleAllRows() {
    setSelectedRows(prev =>
      prev.size === parsedItems.length ? new Set() : new Set(parsedItems.map((_, i) => i))
    );
  }
```

## Workflow after this patch

1. Codes auto-suggest categories as before.
2. To fix a group: tick the rows (or use the header select-all / tick a few),
   pick a category in the **Bulk assign** dropdown, click **Assign to selected (N)**.
3. Selected rows highlight amber; selection clears after assigning.
4. "Set unassigned" / "Set all" still work for the broad strokes.

> Uses native checkboxes (same style as the existing import-mode radios) — no new
> imports needed.

## Verify

- Import a BOQ with 100+ rows → Step 2.
- Tick the header checkbox → all rows select; tick a few rows → only those select
  (header shows indeterminate state).
- Choose a category, click **Assign to selected (N)** → only ticked rows get that
  category, selection resets. Unassigned counter updates and the proceed gate unlocks
  once everything has a category.
