Issue 1:
Site Requirements Queue / Tomorrow Plans & Site Requirements exists, but it is not visible anywhere in Admin/PM login or hubs.

Issue 2:
On Site Engineer Home, the Readiness for Today’s Work section is visible, but when site engineer clicks “Confirm Readiness & Start Site Work”, it fails with:

403: Cannot update readiness for your own submission

This permission rule is incorrect for readiness confirmation.

Please fix both issues carefully.

B. Fix Readiness confirmation permission

The current error is:

403: Cannot update readiness for your own submission

Please distinguish between two different actions:

1. Allocation / approval / arrangement update

This is done by PM/Admin/Store/Mechanical.

The site engineer should not be allowed to approve or arrange his own submitted requirement.

Examples:
- Approved
- Arranged
- Sent to Store
- Sent to Purchase
- Sent to Plant
- Equipment allocated
- Expected at site by time
- Rejected
- Need clarification

2. Morning readiness confirmation

This is done by the site engineer/supervisor on his own Site Home before starting work.

This must be allowed even if he submitted the original Tomorrow Plan.

Examples:
- Required material available at site / expected today / partly available / not available
- Required equipment available at site / expected today / partly available / not available
- Required labour available / partly available / not available
- shortage remarks
- Confirm Readiness & Start Site Work

Required backend/API rule:

- Block site user from updating allocation/approval status on his own submission.
- Allow site user to save morning readiness confirmation for his own submitted requirement.
- Saving readiness should not change approval/allocation status.
- Saving readiness should only create/update readiness confirmation fields for site/date/user.
- After readiness save, proceed to Start Today’s Site Work.
- If any group is partly available / not available / issue, mark “Started with shortage” and show shortage alert to PM/Admin.

C. Navigation

- continue to Start Today’s Site Work
- or return to Site Engineer Home if the user cancels/comes back

- return to Site Requirements Queue
