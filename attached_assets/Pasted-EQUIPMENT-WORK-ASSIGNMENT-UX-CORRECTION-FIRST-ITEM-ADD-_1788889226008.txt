EQUIPMENT WORK ASSIGNMENT UX CORRECTION
FIRST ITEM + ADD ITEM BUTTON + CLOCK-TIME VALIDATION

Implement only this focused correction/reorganisation.

Goal:
1. Keep machine-day meter/time facts separate from BOQ work assignments.
2. Rename the first work-allocation interaction so it does not say "Add another activity" before any item exists.
3. Use "Assign Item" for the first BOQ work item.
4. Use a compact + Add Item control after the last assignment row.
5. Keep that + Add Item control immediately below the current last row as more assignments are added.
6. Validate assignment time against machine-day CLOCK duration, not meter working hours.
7. Preserve all existing equipment, diesel, hire, reporting and persistence logic.

--------------------------------------------------
1. MACHINE DAY REMAINS THE PARENT RECORD
--------------------------------------------------

The existing parent equipment record continues to represent the full machine day / shift.

Parent machine-day facts include:

- Equipment
- Registration / equipment number
- Operator
- Hire / entry type
- Opening Meter
- Closing Meter
- Parent Start Time
- Parent End Time
- Meter Working Hours / Distance
- Clock Duration
- Diesel issued
- Opening / Closing Tank
- Fuel performance
- Breakdown / Stoppage
- hire attendance / commercial source behavior

Do not move BOQ assignment logic into these parent facts.

--------------------------------------------------
2. WORK ASSIGNMENT — CHANGE THE USER LANGUAGE
--------------------------------------------------

Rename the visible section from generic activity wording to:

WORK ASSIGNMENT

The field engineer is assigning BOQ items to the machine-day.

Avoid "Activity" terminology where possible in this UI.

Use:

- Assign Item
- Add Item
- BOQ Item

Do NOT use:

- Add another activity
- Programme distinction
- Work reach
- Task
- Related BOQ Item

--------------------------------------------------

[ Assign Item ]

--------------------------------------------------

For the FIRST assignment:

default assignment Start Time = parent Start Time

If this is the only assignment and parent End Time exists:
it may default assignment End Time = parent End Time

Keep both editable.

Do not overwrite existing manually entered values.

--------------------------------------------------
6. "+ ADD ITEM" POSITION
--------------------------------------------------

Once at least one assignment exists:

show:

[ + Add Item ]

IMMEDIATELY AFTER THE LAST ASSIGNMENT ROW.

Do not keep the Add Item button in the section heading.

Do not require the user to scroll upward to add another BOQ item.

Example:

Assignment 1
...

Assignment 2
...

[ + Add Item ]

If Assignment 3 is added:
the button moves below Assignment 3.

The button should always follow the current final row.

--------------------------------------------------
7. ADD ITEM DEFAULT START
--------------------------------------------------

When + Add Item is pressed:

New row:
- BOQ Item = blank
- Start Time = previous assignment End Time, if available
- End Time = blank
- Duration = auto-calculated once times are complete

Example:

Assignment 1
09:30 → 12:15

Press + Add Item

Assignment 2 defaults:
Start = 12:15
End = blank

--------------------------------------------------
8. ASSIGNMENT TIME IS CLOCK TIME
--------------------------------------------------

Assignment Start / End are CLOCK-TIME segments.

They describe during which part of the parent machine-day that BOQ item was being worked on.

They are NOT meter-hour values.

Therefore:

assignment duration =
End Time − Start Time

--------------------------------------------------
9. VALIDATION LIMIT MUST USE PARENT CLOCK DURATION
--------------------------------------------------

Correct the current validation behavior.

Do NOT use Meter Working Hours as the assignment-time ceiling.

Use:

Parent Clock Duration =
Parent End Time − Parent Start Time

Example:

Parent:
09:30 → 18:10
Clock Duration = 8 h 40 min

Meter:
1388.8 → 1396.2
Meter Working Hours = 7 h 24 min

One assignment:
Roadway Excavation
09:30 → 18:10
Duration = 8 h 40 min

Expected:
VALID

Do NOT show:
"Allocated time exceeds Meter Working Hours limit."

--------------------------------------------------
10. METER WORKING HOURS REMAIN A SEPARATE FACT
--------------------------------------------------

Continue to show:

Meter Working Hours: 7 h 24 min
Clock Duration: 8 h 40 min

These have different meanings.

Meter Working Hours:
actual meter/engine utilisation

Clock Duration:
overall machine-day elapsed time

Do not compare assignment clock segments directly against meter working hours.

--------------------------------------------------
11. ASSIGNMENT VALIDATION RULES
--------------------------------------------------

Assignments must satisfy:

- Start Time exists
- End Time exists
- End > Start
- assignment times lie within parent machine-day Start/End where parent times are known
- no overlaps between assignment rows
- duplicate identical segments blocked
- total assigned clock duration cannot exceed parent Clock Duration
- gaps are allowed
- partial assignment is allowed

Do not force assignments to cover the whole machine day.

--------------------------------------------------

Machine Day: X h Y min

This summary must use CLOCK duration.

Example:

Machine Day: 8 h 40 min
Assigned: 6 h 30 min
Unassigned: 2 h 10 min

Do not label this as meter hours.
