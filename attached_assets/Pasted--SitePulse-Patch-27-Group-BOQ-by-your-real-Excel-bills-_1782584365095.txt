# SitePulse — Patch 27: Group BOQ by your real Excel bills + show full descriptions

Verified against your live repo (commit `6ed56b66`) **and** your file *NH 167 BoQ SK Sample.xlsx*.

## What I found in your Excel (the root cause, confirmed)
Your bills are numbered like this:

| Bill | Title | Item codes |
|---|---|---|
| BILL No. 1 | SITE CLEARANCE | 1.01… |
| BILL No 2 | EARTH WORK | 2.01, 2.03A… |
| BILL No 3 | SUB-BASE AND BASE COURSES | 3.01… |
| BILL No 4 | BITUMINOUS WORKS | 4.01… |
| Bill No 5 | Culverts | 5.01… |
| … | … | … |
| BILL No 12 | HIGHWAY LIGHTING | 12.01… |

But the app's auto-classifier (`suggestWorkCategory` → `mapChapterToCategory`) assumes the
**MoRTH standard chapter scheme**, which is shifted by one bill vs yours:

| Your code | App labels it as | Should be (your bill) |
|---|---|---|
| 1.xx | **Preliminaries** | Site Clearance |
| 2.xx | **Site Clearance** | Earth Work |
| 4.xx | **Sub-base & Base** | Bituminous |
| 5.xx | **Bituminous** | Culverts |

…and the BOQ screen **groups by that wrong standardized bucket** — which is exactly why your
items look "mixed up". **The good news:** the importer already stored your real bills
(`boq_categories` / `categoryName`, e.g. *"BILL No. 1 SITE CLEARANCE"*), so we just need to
group by *that* instead. No re-import needed.

This patch:
1. **Groups & orders the BOQ by your own Excel bills** (verbatim titles, original file order).
2. **Removes the 40-character description truncation** — full text, wrapped, with hover tooltip.

> Note: the standardized `workCategory` is still kept on each item (used by BOM / SNL material
> analytics); we just stop using it as the *display grouping*.

**REPLACE WITH:**

```ts
  // Group strictly by the BOQ's OWN bill structure as imported from Excel
  // (categoryName, e.g. "BILL No. 1 SITE CLEARANCE"), preserving the file's order.
  // Only falls back to the standardized work category / "Uncategorized" when an item
  // genuinely has no bill assigned.
  const billSections = useMemo(() => {
    const map = new Map<string, { name: string; order: number; items: BoqItemWithCategory[] }>();
    for (const item of items) {
      const name =
        (item.categoryName?.trim()) ||
        getWorkCategoryLabel(item.workCategory) ||
        "Uncategorized";
      const so = item.sortOrder ?? Number.MAX_SAFE_INTEGER;
      let bucket = map.get(name);
      if (!bucket) { bucket = { name, order: so, items: [] }; map.set(name, bucket); }
      bucket.items.push(item);
      if (so < bucket.order) bucket.order = so;
    }
    const sections = [...map.values()];
    // Bills appear in their original Excel order (by first row's sortOrder).
    sections.sort((a, b) => a.order - b.order);
    // Within a bill keep the file order, then fall back to item-code order.
    for (const s of sections) {
      s.items.sort((a, b) => {
        const ao = a.sortOrder ?? 0, bo = b.sortOrder ?? 0;
        if (ao !== bo) return ao - bo;
        return compareItemCode(a.itemCode, b.itemCode);
      });
    }
    return sections;
  }, [items]);
```
