Part A — Export / print permission gating

Operational exports use view_reports plus permitted-site checks. No switch to the unused export action. No publishing.

Server

  • Vendor register CSV/Excel: vendor_bills / vendor_bills_view; resolves selected site and filters all bills and vendor names.
  • Vendor bill PDF: same permission; requested bill must be in permitted scope.
  • Plant daily CSV/Excel, individual PDF and bulk ZIP: plant_daily_reports; plants must have an explicit permitted site mapping. Unmapped/shared plants require all-sites access.
  • Heating Excel: plant_heating / plant_heating_trends plus plant-to-site scope.
  • IRN voucher PDF: irn_view / irn_raise plus IRN site; explicit voucher IDs must belong to that IRN.
  • Estimator guide: preserved independent verified estimator-admin cookie and existing 401 rejection contract; it is not login-only.
