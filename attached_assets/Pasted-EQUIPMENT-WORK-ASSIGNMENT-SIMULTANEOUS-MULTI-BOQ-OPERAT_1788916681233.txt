EQUIPMENT WORK ASSIGNMENT — SIMULTANEOUS MULTI-BOQ OPERATION SUPPORT
PLUS COMPACT FIELD-ENTRY UX AND TIME-PICKER FIX

Implement only this focused correction.

GOAL

1. Support one physical equipment work segment being linked to multiple BOQ items when one operation simultaneously contributes to more than one payable BOQ item.
2. Keep physical machine time counted only once.
3. Credit each linked BOQ item with the same equipment contribution for BOM/SNL requirement matching.
4. Keep actual machine cost/diesel/hire counted only once.
5. Keep the editable field form compact: capture data, not analysis.
6. Remove nonessential equipment summary/analysis blocks from the editable form.
7. Fix all time fields so the native/mobile time picker opens properly.
8. Preserve current machine-day parent logic and existing persistence wherever possible.

--------------------------------------------------
1. BUSINESS CASE
--------------------------------------------------

In road works, one physical excavator operation can legitimately contribute to more than one separately payable BOQ item at the same time.

Example:

An excavator performs Roadway Excavation and, in the same physical bucket operation at the same location, cuts and spreads/adjusts that excavated earth into Embankment with Excavated Material.

This is:

- one physical machine operation
- one clock-time segment
- one actual machine usage/cost event

but it contributes to two separate BOQ items:

- Roadway Excavation
- Embankment with Excavated Material

Both BOQ items may independently carry excavator requirement in BOM/SNL.

If SitePulse allows only one BOQ item:
- the second BOQ item keeps showing excavator requirement as unmet
- Work Demand becomes wrong
- plan-vs-actual resource analysis becomes wrong
- BOQ-wise resource/cost analysis becomes misleading

Therefore:

ONE physical segment must support ONE OR MORE linked BOQ items.

--------------------------------------------------
2. PHYSICAL SEGMENT MODEL
--------------------------------------------------

Change the conceptual model from:

one allocation row
=
one BOQ item
+
one start time
+
one end time

to:

one PHYSICAL WORK SEGMENT
=
one start time
+
one end time
+
one duration
+
one or more BOQ item links

Example:

09:30–13:00
3 h 30 min

Linked BOQ Items:
- Roadway Excavation
- Embankment with Excavated Material

Physical machine time:
3 h 30 min

Do NOT count:
7 h

--------------------------------------------------
3. PHYSICAL MACHINE TIME COUNTS ONCE
--------------------------------------------------

For each physical segment:

physical duration =
End Time − Start Time

No matter how many BOQ items are linked, machine physical time is counted once.

Example:

09:30–13:00
BOQ A + BOQ B

Expected:
physical machine time = 3 h 30 min

NOT:
3 h 30 + 3 h 30 = 7 h

This single physical duration is used for:

- machine-day time
- hire attendance
- diesel
- meter utilisation context
- breakdown/stoppage context
- physical equipment usage

--------------------------------------------------
4. BOQ RESOURCE ATTRIBUTION
--------------------------------------------------

Each linked BOQ item receives the full segment duration for equipment requirement matching.

Example:

Segment:
09:30–13:00
Excavator
BOQ A + BOQ B
Duration = 3.5 h

Expected:

BOQ A actual excavator contribution = 3.5 h
BOQ B actual excavator contribution = 3.5 h

But:

overall physical excavator usage = 3.5 h

This distinction is intentional.

--------------------------------------------------

--------------------------------------------------
10. CLOCK-TIME VALIDATION
--------------------------------------------------

Assignment segments are CLOCK-TIME segments.

Do NOT validate against Meter Working Hours.

Use:

Parent Clock Duration =
Parent End Time − Parent Start Time

Each physical segment must lie within the parent machine-day time window.

Example:

Parent:
09:30–18:10

Clock Duration:
8 h 40 min

Meter:
1388.8 → 1396.2
Meter Working Hours:
7 h 24 min

Segment:
09:30–18:10

Expected:
VALID

Do NOT show:
"Allocated time exceeds Meter Working Hours limit."

--------------------------------------------------
11. OVERLAP RULE
--------------------------------------------------

Overlap validation applies between PHYSICAL SEGMENTS only.

Allowed:

Segment 1
09:30–13:00
BOQ A + BOQ B

This is valid.

Not allowed:

Segment 1
09:30–13:00

Segment 2
12:30–15:00

for the same machine/day.

Multiple BOQ links within the same segment are not overlaps.

Roadway Excavation

Expected:
prevent duplicate BOQ link.

20. WORK DEMAND / BOM-SNL REQUIREMENT MATCHING
--------------------------------------------------

For each physical segment:

for every linked BOQ item:
credit the full segment duration against that BOQ item's equipment requirement.

Example:

BOQ A required Excavator = 5 h
BOQ B required Excavator = 4 h

Shared segment:
3.5 h

Expected:

BOQ A remaining = 1.5 h
BOQ B remaining = 0.5 h

Physical excavator usage remains:
3.5 h

Do not double physical machine totals.
