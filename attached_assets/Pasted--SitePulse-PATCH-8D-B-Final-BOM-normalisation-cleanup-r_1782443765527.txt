## 2. Add `normaliseBomMaterial()` in `shared/planningEngine.ts`

Add a pure helper near the BOM calculation section.

Purpose:
Convert raw SDB/SNL/mix/manual material names into practical BOM/procurement names.

Function signature:

```ts
export function normaliseBomMaterial(input: {
  materialName: string;
  uom: string;
  itemDescription?: string;
  itemCode?: string | null;
  layerConfig?: LayerConfig | null;
  supplyType?: "direct" | "plant";
  isAuto?: boolean | null;
}): {
  displayMaterialName: string;
  suggestedMaterialMasterName: string;
  originalNormMaterialName: string;
  materialGroup: string;
  reviewNeeded: boolean;
  normalisationReason: string;
}
```

Rules:

### A. Direct-supply GSB/WMM collapse

If material/BOQ/layer indicates direct GSB/WMM:

* WMM → `WMM Material`
* GSB → `GSB Material`

Detect using:

* `layerConfig.layerType === "granular"`
* `layerConfig.granularSource !== "plant"`
* OR `supplyType === "direct"`
* AND item description / mixType contains WMM/GSB/granular sub-base/wet mix

Do not allow gradation fraction names to remain for direct-supply GSB/WMM.

### B. Bituminous practical names

Preserve already practical names:

* Bitumen VG-30
* Bitumen VG-40
* Aggregate Dust
* Stone Dust
* 6mm Aggregate
* 10mm Aggregate
* 20mm Aggregate
* 40mm Aggregate
* Filler
* LDO / Process Fuel

### C. SDB aggregate gradation fallback

If raw name contains aggregate gradation ranges, normalise to practical market names:

* 63–45 mm → `60mm Aggregate`
* 53–22.4 mm → `40mm Aggregate`
* 45–22.4 mm → `40mm Aggregate`
* 37.5–25 mm → `40mm Aggregate`
* 26.5–19 mm → `20mm Aggregate`
* 25–10 mm → `20mm Aggregate`
* 22.4–11.2 mm → `20mm Aggregate`
* 19–9.5 mm → `10mm Aggregate`
* 13.2–5.6 mm → `6mm Aggregate`
* 9.5–2.36 mm → `6mm Aggregate`
* 4.75 mm and below → `Stone Dust`
* below 2.36 mm → `Stone Dust`
* 75 micron / filler → `Filler`

This is internal logic. Do not ask user to add aliases in Material Master.

### D. Common material names

Normalise:

* HYSD / TMT / reinforcement / steel → `TMT / Reinforcement Steel`
* cement → `Cement`
* sand → `Sand`
* water → `Water`
* emulsion + prime → `Bitumen Emulsion SS-1`
* emulsion + tack → `Bitumen Emulsion RS-1`
* diesel / HSD → `Diesel / HSD`
* LDO / process fuel → `LDO / Process Fuel`

Fallback:
If no rule matches, keep raw material name but set `reviewNeeded = true`.

## 3. Apply normalisation inside `calculateBomDemand()`

In the material loop, before creating the map key:

Current behaviour:

```ts
const key = canonResourceKey(m.materialName);
```

Change to:

```ts
const norm = normaliseBomMaterial({
  materialName: m.materialName,
  uom: m.uom,
  itemDescription: item.description,
  itemCode: item.itemCode,
  layerConfig: item.layerConfig ?? null,
  supplyType: m.supplyType,
  isAuto: m.isAuto,
});

const key = canonResourceKey(norm.displayMaterialName);
```

Use `norm.displayMaterialName` as the final `materialName`.

Extend `BomMaterialRow` and breakdown row safely with optional fields:

```ts
originalNormMaterialName?: string;
suggestedMaterialMasterName?: string;
materialGroup?: string;
reviewNeeded?: boolean;
normalisationReason?: string;
```

Do not remove existing fields.
