1) USE IMMUTABLE SNAPSHOTS

- baseSnapshot = exact estimate state at the moment the scenario is created
- scenarioSnapshot = edited scenario state saved by the user
- workingCalculatorState = temporary live state while editing

The Price Impact report must NEVER compare against the current working calculator state.
It must compare only:
- Base = baseSnapshot
- Revised = scenarioSnapshot

2) SCENARIO CREATION

- create a deep copy of the currently selected estimate state as baseSnapshot
- create another deep copy as initial scenarioSnapshot
- edits must apply only to scenarioSnapshot
- baseSnapshot must remain frozen forever for that scenario

3) SCENARIO SAVE
When user clicks save scenario:
- preserve original baseSnapshot unchanged
- save the edited scenarioSnapshot unchanged
- do not overwrite baseSnapshot when navigating back, saving, or going to overview

- baseSnapshot for base values
- scenarioSnapshot for revised values

- Final Laid Rate by Mix Type

- Procurement Impact
- Internal Check (Post-Variation)

5) EDIT SCENARIO BEHAVIOR

- load scenarioSnapshot into calculator for editing

- do not mutate baseSnapshot during editing
