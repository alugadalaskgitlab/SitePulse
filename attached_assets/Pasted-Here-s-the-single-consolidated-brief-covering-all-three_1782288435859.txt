60|## Set the switch
61|
62|**Dev (so the hubs show while you work):**
63|- Replit left sidebar → **Tools → Secrets** → add `VITE_ENABLE_WORK_PROGRAM` = `true`.
64|- Restart the dev server / rebuild (Vite inlines `VITE_*` at build time, so a restart is needed for it to take effect).
65|
66|**Production (hidden until launch):**
67|- Deployments → your deployment → **Secrets / Environment variables** → set `VITE_ENABLE_WORK_PROGRAM` = `false` (or simply leave it unset — anything other than the exact string `"true"` = hidden).
68|- Redeploy.
69|
70|**To launch later:** set the deployment secret to `true` and redeploy. One flip, no code change.
