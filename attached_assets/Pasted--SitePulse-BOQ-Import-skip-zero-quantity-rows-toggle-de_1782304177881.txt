# SitePulse — BOQ Import: skip zero-quantity rows (toggle, default ON, live count)

Adds a **"Skip rows with zero quantity"** toggle to Step 3 (Review) of the import
wizard. Default **ON**. Shows a live count of how many rows will be skipped, and only
imports rows with `qty > 0` when enabled. Zero-qty rows also stop blocking the
"all items must have a category" gate.

All changes are in **`client/src/components/BoqImportWizard.tsx`**. Purely additive;
apply on top of the checkbox-multiselect patch you already merged.

---

## EDIT 1 — add the toggle state

**FIND:**

```tsx
  const [importMode, setImportMode] = useState<"append" | "replace">("append");
```

**REPLACE WITH:**

```tsx
  const [importMode, setImportMode] = useState<"append" | "replace">("append");
  const [skipZeroQty, setSkipZeroQty] = useState(true);
```

## EDIT 2 — make the category gate ignore skipped rows + compute counts

**FIND:**

```tsx
  const canProceedStep1 = colMap.description != null && colMap.unit != null && colMap.boqQty != null;
  const unassignedCount = itemWorkCats.filter(c => c === "").length;
  const canProceedStep2 = unassignedCount === 0;
```

**REPLACE WITH:**

```tsx
  const canProceedStep1 = colMap.description != null && colMap.unit != null && colMap.boqQty != null;
  const zeroQtyCount = parsedItems.filter(it => (it.boqQty ?? 0) <= 0).length;
  const importCount = skipZeroQty ? parsedItems.length - zeroQtyCount : parsedItems.length;
  // Rows that will be skipped don't need a category, so they don't block the gate.
  const unassignedCount = itemWorkCats.filter((c, i) => c === "" && !(skipZeroQty && (parsedItems[i]?.boqQty ?? 0) <= 0)).length;
  const canProceedStep2 = unassignedCount === 0;
```

## EDIT 3 — drop zero-qty rows from the final import payload

**FIND:**

```tsx
  function buildFinalItems() {
    return parsedItems.map((item, idx) => ({
      ...item,
      workCategory: itemWorkCats[idx] || undefined,
    }));
  }
```

**REPLACE WITH:**

```tsx
  function buildFinalItems() {
    return parsedItems
      .map((item, idx) => ({
        ...item,
        workCategory: itemWorkCats[idx] || undefined,
      }))
      .filter(item => !(skipZeroQty && (item.boqQty ?? 0) <= 0));
  }
```
