# SitePulse — Patch 20: Diesel/LDO fuel capture, fuel fields in Planning Masters, back-navigation

Depends on Patches 16, 17, 19. **This patch adds DB columns — you must run `npm run db:push` after applying.**

## What this fixes
1. **Diesel not captured.** `planning_equipment_types` had only output fields. The demand
   engine computes "Diesel / HSD" from each equipment's `fuelType` + fuel norm (L/hr), but
   those didn't exist on the planning master, so diesel was always blank. This patch adds
   `consumptionNorm` (L/hr) + `fuelType`, seeds standard diesel norms, reads them into the
   BOM, and exposes the fields in the Planning Masters equipment dialog.
   (LDO for HMP already flows from the mix template `ldoNorm` once Patch 19 is in.)
2. **Back navigation missing** on Planning Masters and Norms Library — added "← Back to
   Work Programme" links.
3. **Bitumen shown twice per item** — already fixed by **Patch 19** (single binder row).

### C2. Seed + backfill the fuel norms (so existing rows get them too)

**FIND:**

```ts
    let equipmentInserted = 0;
    for (const seed of MORTH_EQUIPMENT_SEED) {
      if (equipNames.has(seed.name.toLowerCase())) continue;
      await db.insert(planningEquipmentTypes).values({
        name: seed.name,
        category: seed.category,
        sortOrder: seed.sortOrder,
        standardOutputs: seed.standardOutputs,
        isActive: true,
      });
      equipmentInserted++;
    }
```

**REPLACE WITH:**

```ts
    let equipmentInserted = 0;
    for (const seed of MORTH_EQUIPMENT_SEED) {
      const fuel = MORTH_EQUIPMENT_FUEL_NORMS[seed.name];
      if (equipNames.has(seed.name.toLowerCase())) {
        // Backfill fuel norms onto an already-seeded equipment type (idempotent).
        if (fuel) {
          await db.update(planningEquipmentTypes)
            .set({ consumptionNorm: fuel.ltrPerHr, fuelType: fuel.fuelType })
            .where(eq(planningEquipmentTypes.name, seed.name));
        }
        continue;
      }
      await db.insert(planningEquipmentTypes).values({
        name: seed.name,
        category: seed.category,
        sortOrder: seed.sortOrder,
        standardOutputs: seed.standardOutputs,
        consumptionNorm: fuel?.ltrPerHr ?? null,
        fuelType: fuel?.fuelType ?? null,
        isActive: true,
      });
      equipmentInserted++;
    }
```

## After applying (order matters)
1. Apply Patches 16, 17, 19, then 20.
2. **`npm run db:push`** (creates `consumption_norm` + `fuel_type` columns). Type `yes` if it asks.
3. `npm run check`, rebuild.
4. **Planning Masters → Seed MoRTH Defaults** (re-click — it now backfills fuel norms onto your existing equipment).
5. Work Programme → **Auto-build recipes** (re-run, so items pick up the equipment with fuel norms).
6. **BOM → Materials:** you should now see **"Diesel / HSD" (L)** with monthly demand, and
   **"LDO / Process Fuel"** for the HMP bituminous items.
7. Open **Planning Masters → edit any equipment**: the **Fuel Type** + **Fuel Norm (L/hr)**
   fields are now editable.
8. Planning Masters & Norms Library now show a **← Back to Work Programme** link.

> Diesel norms above are typical MoRTH/site values — adjust any per your fleet in
> Planning Masters and re-run Auto-build recipes.
