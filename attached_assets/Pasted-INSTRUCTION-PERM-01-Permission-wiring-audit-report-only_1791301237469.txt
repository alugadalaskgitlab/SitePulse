A — BUILD THE MAP
=====================================================================
A1. Write a script (committed, re-runnable, e.g. `scripts/permission-audit.ts`) that walks the repo and produces one row per (section, action) pair — all 82 x 8, including pairs that are greyed and pairs that do not exist in the UI map.

Each row must carry:
  - section key, section label as shown on screen
  - action key, action label as shown on screen (the column header)
  - UI STATE: tickable / grey / missing-from-UI-map
