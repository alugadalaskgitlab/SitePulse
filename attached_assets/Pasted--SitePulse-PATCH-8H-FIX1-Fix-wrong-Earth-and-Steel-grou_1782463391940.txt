# SitePulse — PATCH 8H-FIX1: Fix wrong Earth and Steel grouping in Key Material BOM

Current issue after Patch 8H:
Material BOM is restricted to 5 groups, but grouping is wrong.

Observed wrong output:

1. `Earth / Borrow Soil` includes:

   * foundation excavation
   * roadway excavation
   * fly ash
   * backfilling behind walls/abutments
     These should not all be borrow earth.

2. `Cement` includes all HYSD/TMT reinforcement rows.
   Reinforcement rows must show as `TMT / Reinforcement Steel`, not Cement.

Root causes:

1. `isEarthworkBoqItem()` is too broad.
2. The key material row loop calls `normaliseBomMaterial()` again, which can override generated key material names based on BOQ description.
3. `normaliseKeyMaterialName()` does not preserve `TMT / Reinforcement Steel`.

Do not change:

* BOQ import
* BOQ grouping
* SNL mapping
* Work Programme bars
* Labour calculation
* Equipment calculation
* Stock
* IRN/PI
* Dashboard
* UI layout

Only edit:

* `shared/planningEngine.ts`

## 1. Replace `isEarthworkBoqItem()`

Find the existing function:

```ts
function isEarthworkBoqItem(item: BomInputItem): boolean {
  const desc = item.description;
  const unit = normaliseUnit(item.unit);

  if (unit !== "CUM") return false;

  return (
    /earthwork|embankment|subgrade|shoulder|median\s*filling|borrow\s*soil|selected\s*soil|soil\s*fill|filling/i.test(desc) &&
    !/filter\s*media|stone\s*pitching|pcc|rcc|concrete|gsb|wmm|granular\s*sub[-\s]*base|wet\s*mix/i.test(desc)
  );
}
```

REPLACE with:

```ts
function isEarthworkBoqItem(item: BomInputItem): boolean {
  const desc = item.description.toLowerCase();
  const unit = normaliseUnit(item.unit);

  if (unit !== "CUM") return false;

  // Explicit exclusions: these are not borrow earth demand.
  if (
    /foundation|footing|abutment|pier|wing\s*wall|return\s*wall|drain|culvert|pipe|trench|structure|back\s*filling|backfilling|behind\s*abutment|behind\s*wall|filter\s*media|stone\s*pitching|pcc|rcc|concrete|gsb|wmm|granular\s*sub[-\s]*base|wet\s*mix/i.test(desc)
  ) {
    return false;
  }

  // Only main road/formation earthwork should enter Material BOM V1.
  return (
    /embankment|subgrade|earthen\s*shoulder|shoulder|median\s*filling|borrow\s*soil|selected\s*soil/i.test(desc)
  );
}
```

## 2. Add separate Fly Ash detection

Add this helper immediately after `isEarthworkBoqItem()`:

function isFlyAshBoqItem(item: BomInputItem): boolean {
  const desc = item.description.toLowerCase();

  return unit === "CUM" && /fly\s*ash/i.test(desc);

## 5. Preserve steel name in `normaliseKeyMaterialName()`

Inside `normaliseKeyMaterialName(item, m)`, add this at the very top after `raw`, `name`, and `desc` are defined:

```ts
if (/tmt|hysd|reinforcement|reinforcing\s*steel|steel\s*reinforcement|rebar/i.test(raw)) {
  return "TMT / Reinforcement Steel";
}
```

So the start should look like:

```ts
function normaliseKeyMaterialName(item: BomInputItem, m: KeyBomMaterialInputRow): string {
  const raw = m.materialName || "";
  const name = raw.toLowerCase();
  const desc = item.description.toLowerCase();

  if (/tmt|hysd|reinforcement|reinforcing\s*steel|steel\s*reinforcement|rebar/i.test(raw)) {
    return "TMT / Reinforcement Steel";
  }

  if (/gsb material/i.test(raw)) return "GSB Material";
  if (/wmm material/i.test(raw)) return "WMM Material";
```
