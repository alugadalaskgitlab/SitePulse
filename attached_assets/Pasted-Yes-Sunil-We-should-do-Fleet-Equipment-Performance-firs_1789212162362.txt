- which machine
- whether owned or hired
- who owns it if hired
- how much it worked
- how long it was on duty
- how much diesel was issued
- how much diesel was actually consumed
- how that consumption compares with the machine norm

complexity from the normal report.

4. PERIOD CALCULATIONS

For the selected date range:

Opening Meter
= first valid log's opening meter in that period

Closing Meter
= last valid log's closing meter in that period

Working Hours
= total actual working/meter hours recorded for that equipment in the period

Clock Duration
= sum of each usage log's Start Time → End Time duration

Do NOT calculate Clock Duration as elapsed calendar time between first and last date.

Diesel Issued
= total diesel added/issued to that equipment during the selected period

Opening Tank
= opening tank balance from the first valid equipment log in the period

Closing Tank
= closing tank balance from the last valid equipment log in the period

Diesel Consumed
= Opening Tank + Diesel Issued - Closing Tank

IMPORTANT:
Only calculate Diesel Consumed when the required first Opening Tank and last
Closing Tank are reliably available.

If either is missing/unconfirmed:
show "Incomplete" or "—".
Do not invent a value.

Expected Diesel
= existing equipment consumption norm applied to actual activity using the
existing correct norm logic.

Difference
= Actual Diesel Consumed - Expected Diesel

Show this as litres, e.g.:

+12 L
-8 L

Do NOT show percentage variance.

Consumption Rate
= actual consumption in the appropriate machine unit, for example:
L/hr for hour-meter equipment
L/km for kilometre-based equipment
or another existing valid meter/activity unit.

Do not combine incompatible units.
