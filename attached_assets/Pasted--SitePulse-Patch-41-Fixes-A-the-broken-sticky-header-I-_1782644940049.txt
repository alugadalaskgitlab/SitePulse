## PART B — Stop the duplicate breakdown rows (supersedes Patch 37 Part A)
**File:** `shared/planningEngine.ts`
Patch 37 keyed each contributor by `item.id`, which made 6 identical DBM sub-rows show as 6 meaningless duplicates. Key instead by **itemCode + description** so true duplicates merge while genuinely distinct lines stay separate. This line appears **3 times** (materials / equipment / labour) — **replace ALL 3**.

**FIND (×3):**
```ts
        const bk = String(item.id ?? item.itemCode ?? item.description ?? "");
```
**REPLACE (×3):**
```ts
        // Merge only TRUE duplicates (same itemCode AND same description) so 6 identical
        // DBM sub-rows collapse to one contributor, while genuinely distinct lines that
        // share a parent itemCode (steel Foundation/Sub/Super) or repeat across bills
        // (GSB in Bill 3 vs Bill 10) still show separately.
        const bk = String((item.itemCode ?? "") + "|" + (item.description ?? ""));
```
