# SitePulse — PATCH 8E: Material BOM source priority + RMC mix design reuse + Road Estimator-style Materials/Labour display

Current status:
BOM has improved, but it is still not behaving like the intended contractor-friendly BOM.

Observed issues:

1. GSB/WMM direct supply is shown, but the same BOQ items still also appear under aggregate fractions.
2. Raw SDB aggregate gradation names are still leaking into final Material BOM.
3. Material rows are not sorted/grouped in a practical contractor/procurement order.
4. Expanded rows still show unnecessary “Source / BOQ Item” header style.
5. Material BOM should come from project execution decisions and mix templates/JMF/designs, not raw SDB material rows for major mix/layer items.
6. Concrete/RMC mix designs already exist in RMC Operations / mix templates and must be reused.
7. Labour demand should remain SDB/SNL-based, but display should be Road Estimator-style grouped formula rows.

Do not change:

* BOQ import
* BOQ category grouping
* SNL mapping status/confidence logic
* Work Programme bars
* Stock logic
* IRN/PI manual workflows
* Dashboard
* Equipment calculation logic in this patch

Primary files:

* `server/routes.ts`
* `shared/planningEngine.ts`
* `client/src/pages/WorkDemand.tsx`

Reference model only:

* `road-estimator/frontend/src/pages/BillOfMaterials.js`
* Use its grouped BOM display pattern, not its code.

## 1. Material BOM source priority

For MATERIAL BOM only, apply this priority:

1. Project direct-supply decision

   * GSB direct supply → `GSB Material`
   * WMM direct supply → `WMM Material`

2. Project mix template / JMF / mix design

   * DBM / BC / BM / SDBC → HMP mix template / JMF
   * Concrete / PCC / RCC → existing RMC Operations mix design / concrete mix template

3. BOQ quantity as direct material

   * filter media
   * stone
   * pipe
   * bearing
   * expansion joint
   * sealant
   * dowel bars / plastic sheath
   * sign boards / reflectors / studs
   * other direct material items

4. SDB/SNL material rows only for simple non-mix items where no mix template/direct-supply decision is required.

5. If project setup/mix template is missing, show a setup warning. Do not fall back to raw SDB aggregate fractions as final procurement materials for major mix/layer items.

Important:
SDB/SNL can continue to supply labour norms and equipment reference norms. This patch changes only material BOM source selection and display.

## 2. Add helper functions in `server/routes.ts`

Near the BOM endpoint helper functions, add:

```ts
function isMaterialDrivingLayerItem(item: any): boolean {
  const lc = item.layerConfig as LayerConfig | null;
  const desc = String(item.description ?? "").toLowerCase();
  const cat = String(item.workCategory ?? "").toLowerCase();

  if (lc?.layerType && lc.layerType !== "none") return true;

  return (
    /\bgsb\b|granular\s*sub[-\s]*base|wet\s*mix|\bwmm\b|dbm|dense\s*bituminous|bituminous\s*concrete|\bbc\b|bituminous\s*macadam|\bbm\b|sdbc|prime\s*coat|tack\s*coat|pcc|rcc|cement\s*concrete|concrete/i.test(desc) ||
    /subbase|base|bituminous|concrete/i.test(cat)
  );
}

function isSimpleDirectMaterialItem(item: any): boolean {
  const desc = String(item.description ?? "").toLowerCase();

  return (
    /filter\s*media|stone\s*spalls|stone\s*pitching|boulder|pipe|np3|np4|hdpe|bearing|expansion\s*joint|joint\s*sealant|sealant|dowel|plastic\s*sheath|geotextile|separation\s*membrane|sign\s*board|stud|marker|reflector|kerb|railing|crash\s*barrier|anchor|anchorage/i.test(desc)
  );
}

function isRawSdbAggregateName(name: string): boolean {
  const s = String(name ?? "").toLowerCase();

  return (
    /\d+(\.\d+)?\s*mm.*\d+(\.\d+)?\s*mm/.test(s) ||
    /below\s*\d+(\.\d+)?\s*mm/.test(s) ||
    /\d+(\.\d+)?\s*mm\s*and\s*below/.test(s) ||
    /percent|per\s*cent|gradation|graded\s*aggregate|coarse\s*graded|fine\s*graded/i.test(s)
  );
}

function detectConcreteGrade(text: string): string | null {
  const s = String(text ?? "").toUpperCase();
  const m = s.match(/\bM\s*([0-9]{2,3})\b/);
  return m ? `M${m[1]}` : null;
}

function isConcreteLayerOrItem(item: any): boolean {
  const lc = item.layerConfig as LayerConfig | null;
  const desc = String(item.description ?? "").toLowerCase();
  return lc?.layerType === "concrete" || /pcc|rcc|cement\s*concrete|plain\s*cement\s*concrete|reinforced\s*cement\s*concrete|concrete/i.test(desc);
}

function isBituminousLayerOrItem(item: any): boolean {
  const lc = item.layerConfig as LayerConfig | null;
  const desc = String(item.description ?? "").toLowerCase();
  return lc?.layerType === "bituminous" || /dbm|dense\s*bituminous|bituminous\s*concrete|\bbc\b|bituminous\s*macadam|\bbm\b|sdbc/i.test(desc);
}
```

## 4. Modify BOM material resolution in `server/routes.ts`

Inside:

```ts
app.get("/api/boq/projects/:id/bom", async (req, res) => {
```

inside the `expandedItems = items.map(item => { ... })` block, adjust material selection logic.

Required logic:

```ts
const lc = (item as any).layerConfig as LayerConfig | null;
const manualMaterials = item.materials.filter((m: any) => !m.isAuto);
const materialDriving = isMaterialDrivingLayerItem(item);
const simpleDirect = isSimpleDirectMaterialItem(item);
const concreteGrade = detectConcreteGrade((item as any).description ?? "");

if (manualMaterials.length > 0 && !materialDriving) {
  return {
    ...item,
    materials: manualMaterials,
    isProgrammed: barItemIds.has(item.id),
  };
}

if (lc && lc.layerType && lc.layerType !== "none") {
  let resolvedMixTemplateId: number | null = lc.mixTemplateId ?? null;

  if (!resolvedMixTemplateId && lc.layerType === "bituminous" && lc.mixType) {
    resolvedMixTemplateId =
      mixTypeToTemplateId.get(lc.mixType.toUpperCase()) ??
      mixTypeToTemplateId.get(normaliseMixType(lc.mixType)) ??
      null;
  }

  if (!resolvedMixTemplateId && lc.layerType === "bituminous" && (item as any).workCategory) {
    const cat = (item as any).workCategory as string;
    resolvedMixTemplateId =
      mixTypeToTemplateId.get(cat.toUpperCase()) ??
      mixTypeToTemplateId.get(normaliseMixType(cat)) ??
      null;
  }

  // Concrete/RMC template resolution should reuse existing mix template records.
  // Match by detected grade such as M15/M20/M25/M30 where possible.
  if (!resolvedMixTemplateId && lc.layerType === "concrete" && concreteGrade) {
    resolvedMixTemplateId =
      mixTypeToTemplateId.get(concreteGrade.toUpperCase()) ??
      mixTypeToTemplateId.get(normaliseMixType(concreteGrade)) ??
      null;
  }

  const mixTemplate = resolvedMixTemplateId ? mixTemplateMap.get(resolvedMixTemplateId) : null;

  const derived = deriveMaterialsFromLayerConfig(lc, item.unit, mixTemplate ?? undefined);

  const derivedSupplyType: "direct" | "plant" | undefined =
    lc.layerType === "granular" && lc.granularSource !== "plant" ? "direct"
    : lc.layerType === "granular" && lc.granularSource === "plant" ? "plant"
    : lc.layerType === "bituminous" ? "plant"
    : lc.layerType === "spray_coat" ? "direct"
    : lc.layerType === "concrete" ? "plant"
    : undefined;

  if (derived.length > 0) {
    return {
      ...item,
      materials: derived.map(dm => ({
        id: 0,
        boqItemId: item.id,
        materialName: dm.materialName,
        uom: dm.uom,
        qtyPerBoqUnit: dm.qtyPerBoqUnit,
        wastagePct: 0,
        isClientSupplied: false,
        isAuto: true as const,
        sortOrder: 0,
        createdAt: null,
        supplyType: derivedSupplyType,
      })),
      materialSetupWarning: null,
      isProgrammed: barItemIds.has(item.id),
    };
  }

  if (materialDriving) {
    return {
      ...item,
      materials: [],
      materialSetupWarning:
        lc.layerType === "bituminous"
          ? "Mix template/JMF required for bituminous material demand"
          : lc.layerType === "concrete"
          ? `Concrete/RMC mix design required${concreteGrade ? ` for ${concreteGrade}` : ""}`
          : "Material setup required for this layer item",
      isProgrammed: barItemIds.has(item.id),
    };
  }
}

// If item is clearly a major material-driving layer item but no usable layer/template exists,
// do not allow raw SDB aggregate gradation rows into Material BOM.
if (materialDriving && !simpleDirect) {
  return {
    ...item,
    materials: [],
    materialSetupWarning:
      isConcreteLayerOrItem(item)
        ? `Concrete/RMC mix design required${concreteGrade ? ` for ${concreteGrade}` : ""}`
        : isBituminousLayerOrItem(item)
        ? "Mix template/JMF required for bituminous material demand"
        : "Layer/mix setup required for material demand",
    isProgrammed: barItemIds.has(item.id),
  };
}

// Simple direct material items can use existing rows.
// For non-simple/non-layer items, remove raw SDB aggregate gradation rows.
const cleanedExistingRows = item.materials.filter((m: any) => {
  if (!m.materialName) return false;
  if (isRawSdbAggregateName(m.materialName) && !simpleDirect) return false;
  return true;
});

return {
  ...item,
  materials: cleanedExistingRows,
  materialSetupWarning: null,
  isProgrammed: barItemIds.has(item.id),
};
```

Adjust exact field names if local schema differs.

Key point:
For major layer/mix items, do not merge old SDB/SNL material rows into material BOM after deriving from layerConfig/mix template.
